# 🏝️ ちいさな島の宝もの (Islet Treasures)
### 〜 言葉のないノンバーバル・コミュニケーション箱庭アドベンチャー 〜

言葉の通じないちいさな孤島の住人たちと、身振り手振り（エモート）やアイテムのやり取りで心を通わせ、4つの宝物を集めて島の真実を解き明かす癒し系謎解きゲームです。

---

## 🎮 遊び方 & コミュニケーションのヒント

1. **島の探索 & アイテム収集**:
   - `[W][A][S][D]` または `[矢印キー]` で島を歩き回ります。
   - 浜辺や森、古井戸の近くに落ちているアイテム（🍎木の実、🐚桜貝、🍄光るキノコ、🪙コイン）に近づくと自動で拾えます。

2. **住人とのノンバーバル交流**:
   - 画面下の**エモートボタン**（または `[1]〜[6]` キー）で身振り手振りを伝えます。
   - 画面下の**アイテムスロット**をクリックすると、近くの住人にアイテムを渡せます。
   - 喜ぶと頭上にハート（❤️や💖）が出て宝物を譲ってくれます。失敗しても怒った顔（💢）をするだけでペナルティはありません！

3. **住人たちと宝物のヒント**:
   - 🐻 **森のクマモドキ**: お腹がペコペコ…？ 🍎木の実をあげて 👋手を振ると…？
   - 🕊️ **灯台のカモメ爺さん**: 礼儀正しい旅人が好き。 🙇おじぎをして 👏拍手を送ると…？
   - 🦀 **浜辺のカニ坊や**: 恥ずかしがり屋。 💃一緒に踊って 🐚桜貝をプレゼントすると…？
   - 👤 **古井戸の影ぼうし**: 島の秘密の番人。 3つの宝物を持って ❓首をかしげると…？

4. **記憶の手帳 & 祭壇**:
   - 右上の「📖 記憶の手帳」を開くと、集めた宝物と復元された少し切なく不気味な絵日記を読むことができます。
   - 4つの宝物を集めて島の中央にある**「古代の祭壇」**に近づくと、島の封印が解かれエンディングを迎えます。

---

## 🚀 起動方法

```bash
cd islet-treasures
npm run dev
```
ターミナルに表示されるローカルURL（例: `http://localhost:5173`）をブラウザで開いてください。
